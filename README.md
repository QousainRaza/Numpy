# 🧮 NumPy Learning Repository

![Python](https://img.shields.io/badge/Python-3.8%2B-blue?logo=python)
![License](https://img.shields.io/badge/License-MIT-green)
![Jupyter](https://img.shields.io/badge/Notebook-Jupyter-orange?logo=jupyter)

A beginner-friendly collection of **Jupyter notebooks** to help you learn the fundamentals of **NumPy** — array creation, manipulation, file I/O, universal functions, and random number generation. 🚀  

---

## 📘 Contents
- 📂 **`numpy_ndarray.ipynb`** – Basics of `ndarray`: creation, indexing & slicing  
- ⚡ **`arrat_Oriented.ipynb`** – Vectorized computations & performance  
- 🧠 **`universal_Function.ipynb`** – Ufuncs and broadcasting  
- 💾 **`file_Input_Output.ipynb`** – Save/load arrays using `.npy` and `.npz`  
- 🎲 **`Pseudorandom_Num_Gen.ipynb`** – Random number generation examples  

---
